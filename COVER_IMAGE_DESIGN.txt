DEVPOST COVER IMAGE DESIGN SPECIFICATION
Dimensions: 1200×630px (exact Devpost standard)
Format: PNG or JPG (under 1MB)
Created with: Canva (free, no design experience needed)
Time to complete: 15-20 minutes

STEP 1 — CANVA SETUP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to https://www.canva.com
2. Click "Create a design"
3. Search for "Custom size"
4. Enter dimensions: Width 1200, Height 630
5. Click "Create design"

You now have a blank 1200×630 canvas.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 2 — BACKGROUND
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Click on the canvas
2. Right-click → "Change background"
3. Select "Color"
4. Enter hex color: #0a0a0f (dark background, almost black)
5. Click apply

Your canvas is now dark like the visualizer. This matches the HealthGuard visual theme.

STEP 3 — LEFT PANEL (TEXT SECTION)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

TITLE TEXT "HealthGuard"
1. Click "Text" on left sidebar
2. Click "Add a heading"
3. Type: "HealthGuard"
4. Select the text
5. Font: "Poppins" or "Inter" (sans-serif, modern)
6. Size: 72px
7. Weight: Bold (700)
8. Color: #ffffff (white)
9. Position: Top-left area of canvas, approximately:
   - X: 40px from left
   - Y: 60px from top
   - Width: 500px

SUBTITLE TEXT "Regulatory compliance for healthcare AI"
1. Click "Text" → "Add a body text"
2. Type: "Regulatory compliance for healthcare AI"
3. Font: "Poppins" or "Inter"
4. Size: 24px
5. Weight: Regular (400)
6. Color: #aaaaaa (light gray)
7. Position: Below "HealthGuard" title
   - X: 40px from left
   - Y: 160px from top
   - Width: 480px

THREE COLORED BADGES (stacked vertically on left panel)
Position each badge:
  - Starting Y: 280px
  - Spacing between: 24px
  - X: 40px
  - Width: 480px
  - Height: 60px each

BADGE 1 — GREEN (PERMITTED)
1. Click "Shapes" → "Rectangle"
2. Width: 480px, Height: 60px
3. Position at (40, 280)
4. Fill color: #1D9E75 (green)
5. Rounded corners: 12px
6. Add text on top:
   Text: "✓ PERMITTED"
   Font: Poppins Bold, 20px
   Color: #ffffff
   Position: center-left of badge

BADGE 2 — AMBER (OVER-BROAD PHI)
1. Click "Shapes" → "Rectangle"
2. Width: 480px, Height: 60px
3. Position at (40, 364)  [280 + 60 + 24 spacing]
4. Fill color: #EF9F27 (amber/orange)
5. Rounded corners: 12px
6. Add text on top:
   Text: "⚠ Over-broad PHI"
   Font: Poppins Bold, 20px
   Color: #ffffff
   Position: center-left of badge

BADGE 3 — TEAL (AUDIT)
1. Click "Shapes" → "Rectangle"
2. Width: 480px, Height: 60px
3. Position at (40, 448)  [364 + 60 + 24 spacing]
4. Fill color: #0F9D9F (teal)
5. Rounded corners: 12px
6. Add text on top:
   Text: "FHIR AuditEvent ✓"
   Font: Poppins Bold, 20px
   Color: #ffffff
   Position: center-left of badge

STEP 4 — RIGHT PANEL (CODE SNIPPET)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CODE SNIPPET BOX
1. Right side of canvas: X position 620px
2. Click "Shapes" → "Rectangle"
3. Width: 540px, Height: 440px
4. Position: (620, 80)
5. Fill color: #16161e (slightly lighter dark — code editor look)
6. Border: 1px solid #333333
7. Rounded corners: 8px

CODE TEXT (monospace)
1. Click "Text" → "Add body text"
2. Copy-paste this code snippet:

{
  "exception": "Treatment",
  "cfr_section": "§171.302(a)",
  "permitted": true,
  "conditions_met": [
    "Treating provider",
    "Care coordination"
  ]
}

3. Font: "Courier New" or "Roboto Mono" (monospace)
4. Size: 16px
5. Weight: Regular (400)
6. Color: #9FE1CB (light green, matching PERMITTED badge)
7. Line height: 1.6
8. Position: Inside the code box with 20px padding
   - X: 640px
   - Y: 100px
9. Make sure text is fully visible and not cut off

SYNTAX HIGHLIGHTING (optional but recommended)
If you want keywords in different colors:
- Keywords like "exception", "cfr_section": #1D9E75 (green)
- String values like "Treatment", "§171.302(a)": #EF9F27 (amber)
- Boolean like "true": #1D9E75 (green)
- Braces/brackets: #aaaaaa (gray)
